# Workout Tracker Native — v0.8

This is the optional iPhone companion for Workout Tracker. The PWA remains the main local-first gym logger; this native target exists because HealthKit access is available only to native Apple apps.

## What it does

- Requests explicit Apple Health read/write permission.
- Reads bodyweight plus traditional/functional strength workouts.
- Imports the v0.8 JSON bridge generated by `/health` in the PWA.
- Lets you select the exact entries to write to Apple Health.
- Writes bodyweight with `HKQuantitySample`.
- Writes strength workouts with `HKWorkoutBuilder`.
- Exports a readable Apple Health snapshot back to a JSON bridge file.

## Generate the Xcode project

Install XcodeGen once, then:

```bash
cd ios/WorkoutTrackerNative
xcodegen generate
open WorkoutTrackerNative.xcodeproj
```

## Physical iPhone

In Xcode, select the `WorkoutTrackerNative` target → Signing & Capabilities → choose your Apple Developer Team. HealthKit must remain enabled. Then select your iPhone and Run.

The GitHub Actions build intentionally disables code signing and targets the iOS Simulator so source-level Swift/HealthKit compile errors can be caught without storing developer certificates in GitHub.

## Privacy boundary

The native app does not automatically write every workout it sees. Imported bridge entries are presented with toggles and are written only after you press **Write selected to Apple Health**.
