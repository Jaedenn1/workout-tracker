# Workout Tracker

A fast, personal, offline-first lifting tracker.

## Core product goal
Open app → start routine → see previous performance → log weight/reps → complete sets → rest timer → finish workout → persistent history → PRs → simple progression.

## v0.1 scope
- Routines
- Exercises
- Sets: weight, reps, completion
- Previous-performance display
- Workout history
- Local-first persistence
- Basic PR detection
- Simple progression targets

See `docs/RESEARCH_BASELINE.md` for the product decisions guiding the build.
