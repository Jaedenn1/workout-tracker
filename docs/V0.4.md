# Workout Tracker v0.4

## Goal
Turn the single hard-coded Leg Day logger into a small personal training system without losing the fast logging flow from v0.3.

## Added
- Persistent Push / Pull / Legs routines.
- Routine switching with separate in-progress drafts for each routine.
- Routine builder: rename, add, remove, and reorder exercises.
- Create and delete custom routines.
- Searchable exercise library with muscle groups and rep ranges.
- 22 starter exercises across chest, back, shoulders, arms, quads, hamstrings, glutes, and calves.
- Exercise history button on every exercise card.
- Per-exercise analytics: sessions logged, best estimated 1RM, latest volume, recent set history, and e1RM change versus the prior session.
- Existing v0.3 progression, RIR, PR detection, rest timer, workout review, and next-session recommendations remain in place.

## Persistence and migration
- Workout history still uses `workout-tracker:v0.2:history` so existing v0.2/v0.3 history is preserved.
- Legacy v0.2/v0.3 draft storage is migrated into the new per-routine draft system on first load.
- Routines, active routine, and per-routine drafts are stored locally in the browser for v0.4.

## Default routines
### Push Day
Bench Press, Incline Dumbbell Press, Shoulder Press, Lateral Raise, Triceps Pressdown, Overhead Triceps Extension.

### Pull Day
Lat Pulldown, Seated Cable Row, Chest-Supported Row, Rear Delt Fly, Preacher Curl, Hammer Curl.

### Leg Day
Leg Extensions, Pendulum / Hack Squat, Smith Romanian Deadlift, Bulgarian Split Squat, Hamstring Curl, Leg Press, Calf Raises.

## Design decisions
- Exercise history is keyed by exercise ID, not routine name. Moving an exercise between routines does not fragment its progression history.
- Each routine has its own draft so switching routines does not wipe an unfinished workout.
- The exercise library is intentionally compact for now. v0.5 can add custom exercises and a larger catalog without changing the workout history model.

## Next likely milestone
v0.5 should focus on durable cross-device persistence / authentication and PWA installability, followed by richer charts and bodyweight tracking.
