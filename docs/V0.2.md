# v0.2 — Interactive Local Workout Logger

## Goal
Turn the static v0.1 concept into a usable single-device lifting logger before adding accounts, cloud sync, or native mobile features.

## What shipped
- Client-side workout state
- Editable weight and rep inputs
- Per-set completion state
- Automatic 90-second rest timer after set completion
- Live workout timer
- Live set count and session volume
- Previous-set comparison beside every working set
- Simple load suggestion using rep-range completion
- Add-set action per exercise
- Draft autosave in browser localStorage
- Draft recovery after refresh/reopen
- Finish Workout flow
- Local workout history
- Previous workout becomes the source for the next session's displayed history
- Mobile-first styling

## Local storage keys
- `workout-tracker:v0.2:draft`
- `workout-tracker:v0.2:history`

## Progression behavior
For the current implementation, if every previously logged set for an exercise reached the top of that exercise's rep range, the next workout suggests the configured weight increment. Otherwise it suggests repeating the previous load.

This is intentionally simple. A later version should move progression into the domain layer and account for target set count, RIR/RPE, failed sets, partial completion, and configurable progression rules.

## Known constraints
- History is device/browser-specific.
- Clearing browser site data clears local history.
- There is no login or remote database yet.
- Only the starter Leg Day routine is represented in the UI.
- PR detection is not yet surfaced in the interface.
- Rest duration is currently fixed at 90 seconds.
