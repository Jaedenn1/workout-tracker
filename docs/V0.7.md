# Workout Tracker v0.7 — Training Experience

v0.7 adds a dedicated fast Gym Mode at `/gym` while preserving the existing full workout/routine/analytics screen.

## Gym Mode

- PWA launches directly into `/gym`.
- Push / Pull / Legs routine switching.
- Separate v0.7 drafts so the gym-focused logger can evolve without corrupting older drafts.
- Existing v0.2–v0.6 workout history remains the source for previous performance, progression and analytics.

## Set types

Each set can be marked as:

- Work
- Warm-up
- Back-off
- Drop
- Failure

Only **Work** sets feed normal volume, PR detection and progressive-overload calculations. Non-work sets are still preserved inside the session's `v07Details` metadata.

## Faster logging

- Copy previous set.
- −5 lb / +5 lb quick controls.
- +1 rep quick control.
- Delete individual sets.
- Add sets at any time.
- Per-set weight, reps and RIR.
- Per-exercise custom rest time.

## Exercise workflow

- Persistent exercise notes for setup, grip, tempo and cues.
- Pair an exercise with the next movement as a superset.
- Superset rest starts after the paired movement is completed for that set index.
- Substitute an exercise for the current session without rewriting the original exercise's progression history.
- Skip an exercise for the current session.
- Add built-in exercises to the v0.7 routine extras layer.

## Custom exercises

Custom exercises can define:

- Name
- Primary muscle
- Rep range
- Weight increment
- Starting weight
- Number of sets
- Equipment note

Custom exercises are stored separately from the original built-in library so the older app remains compatible.

## Gym utilities

### Plate calculator

Calculates load per side using 45, 35, 25, 10, 5 and 2.5 lb plates and supports a configurable bar weight.

### Warm-up calculator

Creates a simple four-step ramp based on 40%, 60%, 75% and 90% of the working weight.

## Local storage keys added

- `workout-tracker:v0.7:custom-exercises`
- `workout-tracker:v0.7:exercise-notes`
- `workout-tracker:v0.7:rest-seconds`
- `workout-tracker:v0.7:routine-extras`
- `workout-tracker:v0.7:drafts`

The cloud-sync snapshot format is upgraded to version 2 and includes these v0.7 keys when cloud sync is available.

## PWA

- Cache name: `workout-tracker-v0.7`
- `/gym` added to the offline app shell.
- Manifest `start_url` is now `/gym`.

## Compatibility rule

The existing history schema continues to store only standard working sets inside `exercises[].sets`. v0.7-specific set types, notes, substitutions, supersets and rest settings are stored as additional metadata. This prevents warm-up and drop sets from changing older progression calculations.
