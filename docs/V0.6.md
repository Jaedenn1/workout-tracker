# Workout Tracker v0.6 — Progress + Intelligence

v0.6 adds a dedicated progress dashboard without changing the existing workout/session history format.

## New dashboard

Open **📊 Progress** from the app toolbar.

### 7-day training summary
- Sessions
- Working sets
- Total volume
- Training time
- Average RIR

### Strength trends
- Exercise selector
- Estimated 1RM sparkline
- Recent set history
- Session-to-session e1RM changes

### Bodyweight
- Fast bodyweight logging
- Bodyweight trend chart
- Recent weigh-ins
- Bodyweight is included in the cloud-sync payload

### Weekly muscle workload
- Working sets by muscle group
- Relative workload bars
- Per-muscle volume

### Training signals
Simple deterministic signals based on logged history:
- high-effort / training-density fatigue watch
- 3-session estimated-1RM plateau watch

These are training signals only, not medical recovery measurements.

### Target to beat
Uses the existing deterministic progression engine to show:
- Add load / Hold / Beat reps
- suggested load
- target rep range
- explanation for the recommendation

### PR dashboard
Recent estimated-1RM PRs are surfaced in one place.

### 28-day consistency calendar
Shows workout days and multiple sessions on the same day.

## Compatibility

- Existing v0.2+ workout history is reused directly.
- Existing v0.4 routines/drafts are unchanged.
- Existing v0.5 PWA/offline behavior is preserved.
- PWA cache is bumped to `workout-tracker-v0.6`.
- Cloud sync remains local-first and now includes the v0.6 bodyweight log.

## Research alignment

v0.6 continues the project principles from the research baseline:
- fast logging first
- deterministic progression before unnecessary AI
- previous performance and targets remain central
- analytics should answer practical training questions
- no social feed, coaching marketplace, nutrition platform, or subscription clutter
